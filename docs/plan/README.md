# Development Plan

Sprint plans for the study-helper frontend. One file per sprint, per `AGENTS.md`.

## Working rules

- Start with the lowest-numbered sprint whose status is not **Done**.
- Every sprint ends runnable: `pnpm dev` and `pnpm build` succeed. Only the earliest scaffolding sprints may deviate, and only if unavoidable.
- Each sprint ends with a demonstrable increment and satisfies the Definition of Done in `AGENTS.md`.
- Update statuses as stories complete. Move unfinished stories to the next sprint instead of leaving them half-done.
